# Mechanicship System
MechanicShop is an ASP.NET Core (.NET 9) workshop management system for handling customers, vehicles, repair tasks, work orders, labor assignments, invoicing, and real-time work-order updates.  
The solution follows Clean Architecture and applies CQRS with MediatR, DDD concepts, Domain Events, Result Pattern, FluentValidation, EF Core, JWT authentication with refresh tokens, caching, API versioning, and SignalR.
